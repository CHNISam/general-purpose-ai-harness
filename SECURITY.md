# Security Policy

## Supported versions

The default branch and the latest tagged release are the supported versions.

## Reporting a vulnerability

Please do not publish security-sensitive findings in a public issue.

Report vulnerabilities through GitHub's private vulnerability reporting feature when available for this repository. Include:

- affected file/version;
- impact;
- minimal reproduction;
- suggested mitigation if known.

## Scope

Security reports may include:

- unsafe executable enforcement behavior;
- policy bypasses;
- workflow/supply-chain weaknesses;
- malicious fixture or artifact handling;
- documentation that instructs users to expose secrets or credentials.

Methodology disagreements and ordinary Protocol design discussions should use normal issues or pull requests instead.
